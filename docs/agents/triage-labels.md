# Метки триажа

Скиллы говорят о пяти канонических ролях триажа. Этот файл сопоставляет роли с теми строками
меток, которые реально используются в трекере задач репозитория.

| Роль в mattpocock/skills | Метка в нашем трекере | Значение                                        |
| ------------------------ | --------------------- | ----------------------------------------------- |
| `needs-triage`           | `needs-triage`        | Задачу должен оценить мейнтейнер                 |
| `needs-info`             | `needs-info`          | Ждём от автора дополнительной информации         |
| `ready-for-agent`        | `ready-for-agent`     | Полностью описана, готова к автономному агенту   |
| `ready-for-human`        | `ready-for-human`     | Требует реализации человеком                     |
| `wontfix`                | `wontfix`             | Делать не будем                                  |

Когда скилл называет роль (например, «поставь метку готовности к автономному агенту»),
бери строку метки из правого столбца.

Названия здесь совпадают с каноническими: собственного словаря меток триажа в трекере
не заводили, поэтому переименовывать нечего. Если он появится, правь правый столбец —
скиллы будут ставить существующие метки, а не заводить дубликаты.
