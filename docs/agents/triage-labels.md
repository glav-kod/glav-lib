# Метки триажа

Скиллы говорят о пяти канонических ролях триажа. Эта таблица сопоставляет роль с той
строкой метки, которая реально используется в трекере этого репозитория.

| Роль в скиллах    | Метка в нашем трекере | Что означает                                    |
| ----------------- | --------------------- | ----------------------------------------------- |
| `needs-triage`    | `needs-triage`        | Задачу должен оценить сопровождающий            |
| `needs-info`      | `needs-info`          | Ждём от автора дополнительных сведений          |
| `ready-for-agent` | `ready-for-agent`     | Описана полностью, годится для автономного агента |
| `ready-for-human` | `ready-for-human`     | Требует, чтобы делал человек                    |
| `wontfix`         | `wontfix`             | Делать не будем                                 |

Когда скилл называет роль (например, «поставь метку готовности для агента»), бери
строку метки из правой колонки.

Названия совпадают с каноническими: собственного словаря меток триажа в репозитории
не было, поэтому переименовывать нечего. Если он появится, правь правую колонку —
скиллы будут ставить существующие метки, а не заводить дубликаты.
